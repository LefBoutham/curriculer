# Attachments

Store course assets here, such as:

- source PDFs
- images
- data files
- exercise files
- exported artifacts

Keep generated study notes in the numbered section folders, not here.

Use `00 Source Index.md` to track trusted sources that lessons, exercises, flashcards, or quizzes depend on.

When linking assets from course notes, use relative Markdown links or images with useful alt text. Avoid absolute local paths and Obsidian-only embeds for course-critical material.
